# Тайм-менеджмент

Личное приложение для macOS: работа проект-менеджера и личная жизнь в одном месте.
Не заменяет Airtable, а отвечает на другие вопросы: **что делать сегодня, успеваю ли я и куда на самом деле уходит время.**

Все данные хранятся только на вашем Mac: `~/Library/Application Support/TimeManagement/data.json`.
Резервная копия делается раз в день, хранятся последние 30 (папка `backups` рядом).
Интернет не нужен, аккаунтов нет, к браузеру приложение не привязано.

## Установка

1. Откройте вкладку **[Releases](../../releases/latest)** и скачайте файл `Time-Management-…-mac.dmg`.
2. Откройте `.dmg` и перетащите «Тайм-менеджмент» в папку «Программы».
3. Первый запуск. Приложение не подписано сертификатом Apple, поэтому macOS спросит, доверяете ли вы ему:
   - откройте приложение, закройте предупреждение;
   - зайдите в **Системные настройки → Конфиденциальность и безопасность**, внизу нажмите **«Всё равно открыть»**.

   Если macOS пишет «приложение повреждено», выполните в Терминале:
   ```
   xattr -cr "/Applications/Тайм-менеджмент.app"
   ```
4. Чтобы держать под рукой: правый клик по значку в Dock → Параметры → **Оставить в Dock**.

## Как пользоваться (10 минут в день + 15 минут в пятницу)

| Когда | Что делать | Зачем |
|---|---|---|
| Утро, 5 мин | «Сегодня»: разобрать входящие, выбрать 🐸 лягушку, взять до 3 задач | План экономит до 10× времени (Б. Трейси) |
| Весь день | Пришло что-то внезапно — **⌥⌘N** из любого приложения, отметить «от кого» | Голова свободна, видно, сколько съедают звонки и просьбы |
| Работаете над задачей | ▶ таймер. Время видно в строке меню | Личный коэффициент «оценка → факт» |
| Мяч у клиента | Проект → «Жду клиента», дата напоминания | Задержки клиента видны отдельно от ваших |
| Много правок | «＋ Круг правок» | Прогноз сдачи сдвигается автоматически |
| Вечер | «Закрыть день» → перенести незавершённое | Не держать хвосты в голове |
| Пятница, 15 мин | «Итоги недели»: чек-лист + 3 главных результата | Без обзора система разваливается (Д. Аллен) |

### Что умеет

- **Проекты по 5 этапам** (анализ → дизайн → презентация → печать → закрытие). Вводите дату сдачи в печать — план этапов считается назад от неё. Прогноз показывает запас или опоздание в рабочих днях.
- **Шаблоны задач этапа**: при переходе на этап задачи создаются сами, со сроками (включая «Проверка текстов (с Claude)»).
- **Загрузка дня**: часы работы минус буфер на внезапное (по умолчанию 40%) + отдельно личное время. Перегруз видно до того, как он случился.
- **Личный коэффициент**: после 3 выполненных задач с оценкой и таймером приложение знает, во сколько раз вы недооцениваете время, и показывает «реально ~…».
- **Неделя**: перетаскивание задач по дням, вехи этапов и дедлайны.
- **Личное**: здоровье, семья, учёба, быт, финансы, отдых — со своим запасом часов в будни и выходные.

## Горячие клавиши

- **⌥⌘N** — быстрая задача из любого приложения
- **⌘N** — быстрая задача (в приложении)
- **⌘1…⌘5** — Сегодня / Задачи / Проекты / Неделя / Итоги
- В быстрой задаче: **⏎** во входящие, **⌘⏎** на сегодня

## Для разработки

```
npm install
npm start        # запустить
npm test         # тесты логики планирования
npm run dist     # собрать .dmg (только на macOS)
```

Сборка `.dmg` запускается автоматически в GitHub Actions при каждом изменении кода и публикуется в Releases.
